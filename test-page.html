📝 테스트 방법

  1. Video Downloader Pro 확장 프로그램이 설치되어 있는지 확인
  2. 위 동영상에 마우스를 올리면 보라색 다운로드 버튼이 표시됩니다
  3. 버튼을 클릭하면 .mp4 파일이 다운로드되어야 합니다
  4. 확장 프로그램 아이콘에 배지(숫자)가 표시됩니다 (예: 3)

✅ 정상 작동 확인

  • ✅ 다운로드된 파일 확장자가 .mp4여야 합니다
  • ✅ 파일을 재생하면 동영상이 정상 재생되어야 합니다
  • ✅ 파일 크기가 8-10MB 정도여야 합니다

❌ 문제가 있다면

  • ❌ .shtml 파일이 다운로드됨 → URL 감지 오류
  • ❌ 버튼이 안 보임 → 확장 프로그램 미설치 또는 비활성화
  • ❌ 클릭해도 반응 없음 → Console 로그 확인 (F12)

⚠️ 주의사항

YouTube, Netflix 등에서는 작동하지 않을 수 있습니다!

이러한 사이트들은:

  • 복잡한 스트리밍 기술 사용 (DASH, HLS)
  • DRM(저작권 보호) 적용
  • 특별한 인증 토큰 필요

해결책: Windows GUI 프로그램(video_downloader_gui.py)을 사용하세요.
