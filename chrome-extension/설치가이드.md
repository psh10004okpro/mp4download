## 설치 전 확인사항

### ✅ 필수 요구사항

- **Chrome 브라우저** 88버전 이상
  - 또는 **Microsoft Edge** (Chromium 기반)
  - 또는 **Brave**, **Opera**, **Vivaldi** 등 Chromium 기반 브라우저

### 📥 파일 준비

#### 방법 1: GitHub에서 다운로드

1. **저장소 페이지 접속**
   ```
   https://github.com/your-repo/mp4download
   ```

2. **Code 버튼 클릭 → Download ZIP**

3. **다운로드한 ZIP 파일 압축 해제**
   - 원하는 위치에 압축 해제
   - 예: `C:\Programs\VideoDownloaderPro`

4. **chrome-extension 폴더 확인**
   - 압축 해제한 폴더 내에 `chrome-extension` 폴더가 있어야 합니다

#### 방법 2: Git Clone (개발자용)

```bash
git clone https://github.com/your-repo/mp4download.git
cd mp4download/chrome-extension
```

## 설치 방법

### 🚀 Chrome에 설치하기

#### 1단계: 확장 프로그램 페이지 열기

**방법 A: 주소창 사용**
1. Chrome 주소창에 다음을 입력하고 Enter:
   ```
   chrome://extensions/
   ```

**방법 B: 메뉴 사용**
1. Chrome 우측 상단 점 3개 메뉴 (⋮) 클릭
2. "도구 더보기" → "확장 프로그램" 선택

#### 2단계: 개발자 모드 활성화

1. 확장 프로그램 페이지 우측 상단에서 **"개발자 모드"** 토글을 **켜기**로 변경

   ![개발자 모드](https://via.placeholder.com/800x100.png?text=개발자+모드+토글을+켜세요)

   - 토글이 파란색이 되어야 합니다

#### 3단계: 확장 프로그램 로드

1. **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭

2. 폴더 선택 대화상자가 나타나면:
   - 다운로드/압축해제한 `chrome-extension` 폴더 선택
   - **주의**: `mp4download` 폴더가 아닌 그 안의 `chrome-extension` 폴더!

3. **"폴더 선택"** 버튼 클릭

#### 4단계: 설치 확인

설치가 성공하면:

- ✅ 확장 프로그램 목록에 **"Video Downloader Pro"** 나타남
- ✅ 보라색 그라데이션 아이콘 표시
- ✅ 버전 1.0.0 표시
- ✅ Chrome 툴바에 확장 프로그램 아이콘 추가됨

#### 5단계: 툴바에 고정 (선택사항)

1. Chrome 툴바에서 퍼즐 아이콘 🧩 클릭
2. "Video Downloader Pro" 옆 핀 📌 아이콘 클릭
3. 이제 항상 툴바에 표시됩니다

---

### 🔧 Microsoft Edge에 설치하기

Edge도 Chromium 기반이므로 거의 동일합니다:

1. **Edge 주소창에 입력**:
   ```
   edge://extensions/
   ```

2. **개발자 모드 켜기**
   - 좌측 하단 "개발자 모드" 토글 활성화

3. **"압축을 푼 확장 로드"** 클릭

4. `chrome-extension` 폴더 선택

5. 완료!

## 첫 사용 설정

### 🎯 확장 프로그램 테스트

설치 후 바로 테스트해보세요:

#### 테스트 1: 간단한 동영상 사이트

1. **YouTube 접속**
   ```
   https://www.youtube.com
   ```

2. 아무 동영상이나 재생

3. **확인사항**:
   - ✅ 확장 프로그램 아이콘에 숫자 배지 표시 (예: 🎥(1))
   - ✅ 동영상에 마우스를 올리면 보라색 "다운로드" 버튼 표시

4. **다운로드 테스트**:
   - 버튼 클릭
   - Chrome 다운로드 시작 확인

#### 테스트 2: 팝업 확인

1. **확장 프로그램 아이콘 클릭**

2. **팝업 내용 확인**:
   - 감지된 동영상 수 표시
   - 동영상 목록 표시
   - 클릭하면 다운로드

#### 테스트 3: 우클릭 메뉴

1. 동영상에서 **우클릭**

2. **"동영상 다운로드"** 메뉴 확인

3. 클릭하여 다운로드 테스트

### ⚙️ 권한 확인

확장 프로그램이 요청하는 권한:

| 권한 | 필요한 이유 |
|------|------------|
| 📥 다운로드 | 동영상 파일 다운로드 |
| 💾 저장소 | 감지된 동영상 목록 저장 |
| 📄 탭 | 현재 페이지 URL/제목 가져오기 |
| 🌐 웹 요청 | .m3u8, .mpd 스트리밍 URL 감지 |
| 🖱️ 컨텍스트 메뉴 | 우클릭 메뉴 추가 |
| 🔓 모든 사이트 | 모든 웹사이트에서 동영상 감지 |

**걱정하지 마세요!**
- 이 확장 프로그램은 데이터를 외부로 전송하지 않습니다
- 모든 처리는 로컬에서만 이루어집니다
- 소스 코드를 직접 확인할 수 있습니다

## 제거 방법

### 🗑️ 확장 프로그램 제거

#### 완전 제거

1. **확장 프로그램 페이지 열기**
   ```
   chrome://extensions/
   ```

2. **Video Downloader Pro 찾기**

3. **"제거"** 버튼 클릭

4. 확인 대화상자에서 **"제거"** 클릭

#### 임시 비활성화

제거하지 않고 잠시 끄려면:

1. 확장 프로그램 페이지에서
2. Video Downloader Pro의 토글을 **끄기**로 변경
3. 다시 켜면 바로 사용 가능

## 문제 해결

### ❌ "매니페스트 파일이 누락되었거나 읽을 수 없습니다"

**원인**: 잘못된 폴더를 선택했습니다.

**해결 방법**:
1. `mp4download` 폴더가 아닌 `chrome-extension` 폴더를 선택하세요
2. `chrome-extension` 폴더 안에 `manifest.json` 파일이 있는지 확인

**올바른 폴더 구조**:
```
chrome-extension/          ← 이 폴더를 선택하세요!
├── manifest.json         ← 이 파일이 보여야 합니다
├── content.js
├── background.js
├── popup.html
└── ...
```

### ❌ 확장 프로그램이 작동하지 않아요

**체크리스트**:

1. **개발자 모드가 켜져 있나요?**
   - chrome://extensions/ 에서 확인

2. **확장 프로그램이 활성화되어 있나요?**
   - 토글이 파란색이어야 합니다

3. **페이지를 새로고침했나요?**
   - Ctrl + R 또는 F5
   - 확장 프로그램 설치 전에 열었던 페이지는 새로고침 필요

4. **오류 메시지가 있나요?**
   - chrome://extensions/ 에서 "오류" 버튼 확인
   - F12 → Console에서 오류 확인

### ❌ 동영상이 감지되지 않아요

**가능한 원인**:

1. **동영상이 아직 로드되지 않음**
   - 페이지를 완전히 로드한 후 동영상 재생
   - 일부 사이트는 재생해야 URL이 생성됨

2. **지원하지 않는 형식**
   - Flash 동영상: 지원 안 됨 (Chrome도 지원 종료)
   - DRM 보호 콘텐츠: Netflix, Disney+ 등 불가능

3. **Blob URL**
   - Blob URL은 임시 주소로 직접 다운로드 불가
   - Network 탭에서 실제 URL 찾아야 함
   - [HLS 가이드](../HLS_스트림_가이드.md) 참조

### ❌ 다운로드가 실패해요

**원인 1: Referer 제한**
- 이 확장 프로그램은 자동으로 Referer 설정
- 그래도 실패하면 사이트 정책상 차단

**원인 2: 로그인 필요**
- Chrome에서 해당 사이트에 로그인 후 재시도

**원인 3: 일시적 URL**
- 일부 스트리밍 URL은 시간 제한이 있음
- 다시 감지하여 새 URL로 다운로드

### ❌ "개발자 모드" 메뉴가 없어요

**회사/학교 관리 PC인 경우**:
- 관리자 정책으로 개발자 모드가 차단될 수 있습니다
- IT 관리자에게 문의하거나
- 개인 PC에서 사용하세요

### ❌ Chrome이 "안전하지 않은 확장 프로그램" 경고

**정상입니다!**
- Chrome 웹 스토어에서 설치하지 않은 확장 프로그램은 경고 표시
- 소스 코드를 직접 확인했다면 안전합니다

**경고 숨기기**:
1. chrome://extensions/
2. Video Downloader Pro 카드에서
3. "세부정보" 클릭
4. "이 확장 프로그램 신뢰" (일부 버전에만 있음)

### 🎨 아이콘 커스터마이징

아이콘을 변경하고 싶다면:

1. `chrome-extension/icons/` 폴더 열기
2. `icon.svg` 파일을 편집하여 디자인 변경
3. SVG를 PNG로 변환:
   - https://cloudconvert.com/svg-to-png
   - 16x16, 48x48, 128x128 크기로 각각 변환
4. chrome://extensions/ 에서 확장 프로그램 새로고침 (⟳ 버튼)
