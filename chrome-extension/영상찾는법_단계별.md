# 🎥 Chrome 확장 프로그램으로 영상 찾는 방법

복잡한 사이트에서 실제 동영상 URL을 찾아서 다운로드하는 완벽 가이드입니다.

---

## 📌 시작하기 전에

**문제:** Chrome 확장 프로그램이 `.shtml` 파일을 감지했나요?
- 이것은 **웹페이지 파일**이지 동영상이 아닙니다
- **실제 동영상 URL을 직접 찾아야** 합니다

**목표:** 실제 `.mp4`, `.m3u8` 등의 동영상 URL 찾기

---

## 🎯 방법 1: Network 탭으로 찾기 (권장!)

### 1단계: 준비하기

1. **Chrome에서 동영상 페이지 열기**
   ```
   예: https://example.com/video/12345
   ```

2. **F12 키 누르기** (개발자 도구 열기)

3. **Network 탭 클릭**

### 2단계: 필터 설정

Network 탭 상단에서:

**방법 A: Media 필터 (가장 쉬움)**
```
All | Fetch/XHR | JS | CSS | Img | [Media] | Other
                                    ^^^^^^
                                   이것을 클릭!
```

**방법 B: XHR 필터 (스트리밍용)**
- HLS(.m3u8)나 DASH(.mpd)를 찾을 때 사용

**방법 C: 검색 사용**
- Ctrl + F를 눌러서 검색창 열기
- 검색어 입력: `mp4` 또는 `m3u8`

### 3단계: 페이지 새로고침 및 재생

1. **녹화 버튼(●) 확인**
   - 빨간색이어야 합니다
   - 회색이면 클릭해서 켜세요

2. **페이지 새로고침**
   - F5 또는 Ctrl + R

3. **동영상 재생 버튼 클릭**
   - 일부 사이트는 재생해야 URL 로드됨

### 4단계: 동영상 파일 찾기

Network 탭에서 다음과 같은 파일을 찾으세요:

#### ✅ MP4 파일 (가장 쉬움!)

```
Name: video.mp4
Size: 45.8 MB
Type: video/mp4
```

**특징:**
- 파일명에 `.mp4` 포함
- Size가 크다 (보통 10MB 이상)
- Type이 `video/mp4`

#### ✅ M3U8 파일 (HLS 스트리밍)

```
Name: playlist.m3u8 또는 master.m3u8
Size: 1-5 KB (작음!)
Type: application/x-mpegURL
```

**특징:**
- 파일명에 `.m3u8` 포함
- Size가 매우 작다 (몇 KB)
- 여러 .ts 파일과 함께 나타남

#### ✅ MPD 파일 (DASH 스트리밍)

```
Name: manifest.mpd
Size: 1-5 KB
Type: application/dash+xml
```

#### ✅ TS 세그먼트 (스트리밍 조각)

```
Name: segment0.ts, segment1.ts, ...
Size: 각 2-10 MB
Type: video/mp2t
```

**이 경우:** .m3u8 파일을 찾으세요 (위로 스크롤)

#### ❌ 무시해야 할 파일들

```
❌ items1.shtml       → HTML 파일
❌ page.html          → 웹페이지
❌ script.js          → JavaScript
❌ style.css          → 스타일시트
❌ thumbnail.jpg      → 썸네일 이미지
```

### 5단계: URL 복사하기

찾은 파일을 클릭하면 우측에 상세 정보가 표시됩니다:

1. **Headers 탭** 클릭
2. **Request URL** 찾기:
   ```
   Request URL: https://cdn.example.com/videos/abc123/video.mp4
   ```
3. URL **우클릭** → **Copy**
4. 또는 URL을 드래그해서 복사

### 6단계: URL 테스트

1. **새 탭** 열기 (Ctrl + T)
2. 복사한 URL **붙여넣기**
3. Enter

**결과 확인:**

✅ **MP4 성공:**
```
브라우저에서 동영상 재생됨!
→ 동영상에서 우클릭 → "다른 이름으로 비디오 저장"
```

✅ **M3U8 성공:**
```
파일이 다운로드됨 (playlist.m3u8)
→ 이 URL을 Windows GUI 프로그램에 붙여넣기
→ 또는 FFmpeg로 변환
```

❌ **실패:**
```
403 Forbidden 또는 404 Not Found
→ Referer 제한 또는 만료된 URL
→ Windows GUI 프로그램 사용 (자동 처리)
```

## 🎯 방법 2: Chrome 확장 프로그램 사용

### 확장 프로그램이 제대로 작동하려면:

#### 조건:
- ✅ 동영상이 `<video>` 태그 사용
- ✅ src가 `.mp4`, `.webm`, `.m3u8` 등
- ❌ Blob URL이 아님
- ❌ .shtml 같은 웹페이지 아님

#### 사용법:

1. **페이지 열기**
   - 동영상이 있는 페이지 접속

2. **확장 프로그램 아이콘 확인**
   - 숫자 배지 표시됨 (예: 2)
   - 없으면 동영상 감지 안됨

3. **다운로드 방법 선택**

   **A. 마우스 호버:**
   - 동영상에 마우스 올리기
   - 보라색 "다운로드" 버튼 클릭

   **B. 팝업:**
   - 확장 프로그램 아이콘 클릭
   - 목록에서 동영상 선택

   **C. 우클릭:**
   - 동영상에서 우클릭
   - "동영상 다운로드" 선택

#### Console 확인:

확장 프로그램이 무엇을 감지했는지 확인:

1. F12 → **Console** 탭
2. 다음 메시지 찾기:
   ```
   Found valid video (src): https://...video.mp4
   ```

3. 잘못된 URL 거부 메시지:
   ```
   Rejected non-video URL: https://...items1.shtml
   ```

## 💡 실전 예시

### 예시 1: 간단한 MP4

**사이트:** 일반 웹사이트

**Network 탭:**
```
Name: myvideo.mp4
Size: 50.2 MB
Type: video/mp4
URL: https://cdn.example.com/videos/2024/myvideo.mp4
```

**다운로드:**
1. URL 복사
2. 새 탭에서 열기
3. 우클릭 → "다른 이름으로 비디오 저장"

---

### 예시 2: HLS 스트리밍

**사이트:** 스트리밍 사이트

**Network 탭 (XHR 필터):**
```
Name: master.m3u8
Size: 2.1 KB
Type: application/x-mpegURL
URL: https://stream.example.com/hls/video123/master.m3u8
```

**다운로드:**

**방법 A: Windows GUI 프로그램 (권장)**
```
1. video_downloader_gui.py 실행
2. M3U8 URL 붙여넣기
3. "다운로드" 클릭 → 자동으로 MP4 변환!
```

**방법 B: FFmpeg 직접 사용**
```bash
ffmpeg -i "https://stream.example.com/hls/video123/master.m3u8" -c copy output.mp4
```

---

### 예시 3: 여러 TS 세그먼트

**Network 탭:**
```
segment0.ts    5.2 MB
segment1.ts    5.1 MB
segment2.ts    5.3 MB
...
```

**해결:**
1. 위로 스크롤해서 `.m3u8` 파일 찾기
2. 없으면 Filter를 **All**로 변경
3. 검색: `m3u8`
4. 찾은 .m3u8 URL 사용

## 🚫 흔한 문제 해결

### 문제 1: 동영상 파일이 안 보여요

**원인:**
- 페이지 새로고침 안 함
- 동영상 재생 안 함
- 잘못된 필터 선택

**해결:**
1. ✅ Network 탭 열린 상태에서 **F5** (새로고침)
2. ✅ **Media** 필터 선택
3. ✅ 동영상 **재생**하기
4. ✅ 녹화 버튼(●)이 빨간색인지 확인

---

### 문제 2: URL을 복사했는데 403 에러

**원인:**
- Referer 제한 (외부 접근 차단)
- 시간 제한 토큰 (몇 분 후 만료)

**해결:**

**A. Windows GUI 프로그램 사용**
```
자동으로 Referer 헤더 설정
→ run_debug.bat 실행
→ URL 붙여넣기
→ 다운로드
```

**B. 페이지에서 직접 다운로드**
```
1. 동영상 우클릭
2. "다른 이름으로 비디오 저장" 선택
```

---

### 문제 3: Blob URL만 보여요

```
blob:https://example.com/abc-123-def
```

**원인:**
- 동영상이 메모리에만 존재
- 실제 소스 URL 숨김

**해결:**
1. Network 탭에서 Filter를 **All**로 변경
2. Size 컬럼 클릭 (큰 순서 정렬)
3. 가장 큰 파일 찾기 (보통 수십 MB)
4. `.m3u8`, `.ts`, `.mp4` 파일 확인

---

### 문제 4: .shtml만 나와요

```
items1.shtml    500 KB
```

**원인:**
- 사이트가 복잡한 구조 사용
- JavaScript로 동영상 로드

**해결:**
1. ✅ **동영상을 재생**하세요 (중요!)
2. ✅ Network 탭에서 **새로운 요청** 확인
3. ✅ `.mp4`, `.m3u8`, `.ts` 파일 찾기
4. ❌ .shtml은 무시하세요

**빠른 해결:** Windows GUI 프로그램 사용!

## 💬 여전히 찾을 수 없다면?

**최종 해결책: Windows GUI 프로그램**

```bash
# run_debug.bat 실행
run_debug.bat

# 프로그램이 열리면:
1. 동영상 페이지 URL 붙여넣기
2. "동영상 검색" 클릭
3. yt-dlp가 자동으로 실제 URL 찾아줌
4. "다운로드" 클릭!
```

**장점:**
- ✅ 자동으로 실제 URL 찾기
- ✅ Referer, User-Agent 자동 설정
- ✅ HLS/DASH 자동 변환
- ✅ 복잡한 사이트도 OK
